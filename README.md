# spring-core
This repository contains my learning journey for **Spring Core**. It includes the code examples, exercises, and notes that I followed while studying the course.  

## What you'll find here
- Example projects and code snippets from the Spring Core course.
- three packages with different examples and different ways to define config in spring core using (xml config file - annotations - no xml and only java code)

# Purpose
The purpose of this repository is to track my progress and serve as a personal reference while learning Spring Core.  

## Topics Covered
- Inversion of control (IOC)
- Dependency Injection (DI)
- Bean Scopes
- Application Context & Spring Container
- Lifecycle of Beans (init and destroy methods)
- Spring expression language
- Other core concepts of Spring Framework
